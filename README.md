# Portfolio media

Original project photos, engineering visuals, and profile icons used on [mikey-liang.com](https://mikey-liang.com).

## Sources

- TubeSort: original personal project camera captures and vision debug outputs.
- DIY Keyboard: native KiCad PCB render, board layout, and schematic exports from the original design files.
- Pico Says: Michael Liang and Chimdi Anude’s [Cornell ECE 4760 report](https://ece4760.github.io/Projects/Fall2023/ml2226_cca54/index.html), Fall 2023.
- Portfolio: screenshots of the live public website.
- Organization icons: official website assets or Wikimedia logo files. These identify organizations in the résumé and qualification entries.

Exact sources, captions, file sizes, and SHA-256 checksums are recorded in manifest.json. Brand marks remain the property of their respective owners.

- CUAUV Aurora: Michael Liang’s original 2021 camera enclosure assembly drawings, technical report, and user manual; documents linked from the original portfolio.
- CUAUV Polaris: figures 1 and 2 from the [CUAUV 2023 RoboSub team report](https://robonation.org/app/uploads/sites/4/2023/06/TDR_CUAUV_RS23_NUFgRBc.pdf), coauthored by Michael Liang. Vehicle render credited to CUAUV; it provides context for the camera enclosure project.

- Transparent project previews: Aurora’s vehicle render comes unchanged from the [official CUAUV archive](https://cuauv.org/past-subs). The SVG only frames the embedded original for a 2:1 project card. The keyboard is a native KiCad export from the original board, with a transparent background and brighter render lighting. It depicts a bare PCB, not a completed keyboard. Existing originals remain available.

- ECE 3150: Michael Liang’s original February 2023 diode measurements and oscilloscope captures. The clean I-V plot is a direct replot of the measured voltage/current columns with no synthetic or fitted values.
- AMR coursework: Michael Liang’s original 2023 waypoint, localization, mapping, potential-field, and RRT outputs. The final arena image is course-provided context. The RRT trajectory is a lab result, not a claim about final competition performance.
