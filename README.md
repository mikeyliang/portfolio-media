# Portfolio media

Original project photos, engineering visuals, and profile icons used on [mikey-liang.com](https://mikey-liang.com).

## Sources

- TubeSort: original personal project camera captures and vision debug outputs.
- DIY Keyboard: native KiCad PCB render, board layout, and schematic exports from the original design files.
- Pico Says: Michael Liang and Chimdi Anude’s [Cornell ECE 4760 report](https://ece4760.github.io/Projects/Fall2023/ml2226_cca54/index.html), Fall 2023.
- Portfolio: screenshots of the live public website.
- Organization icons: official website assets or Wikimedia logo files. These identify organizations in the résumé and qualification entries.

Exact sources, captions, file sizes, and SHA-256 checksums are recorded in manifest.json. Brand marks remain the property of their respective owners.
